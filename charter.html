1. 상설 가드레일 (A004-5)

"기여 점수는 어떤 경우에도 공용 물리 공간 접근을 차등하지 않는다."

  • 위 1문장은 내부 규정이 아니라 인용 가능한 공개 정책으로 게시한다 (방어 비용을 브랜드 자산으로 전환).
  • 금지 대상의 정밀 한정: 공용 공간에서 비멤버가 체감(가시)하는 기여 점수 기반 서비스 차등 — 좌석 우선권은 전 시간대 금지이며 재도입 불가.
  • 공용 공간 내 재도입은 불가. 상위 기여자 리텐션 추적은 유지/중단 게이트로만 사용한다 (원칙 4 준수).

2. 허용 소비처 화이트리스트 (A004-5 그대로)

기여 점수(존경 레이어)의 소비처는 아래 비가시적 채널로 한정한다:

  1. 기여자 보드/월 (명예의 벽)
  2. 세션 얼리 부킹 윈도 (앱 한정 — 비멤버 비가시)
  3. 세션 개설·주최권 (agency형, R>1 재생산 효과)
  4. 이벤트 초대
  5. 고정 풀 내 F&B 크레딧

적용 제외 (돈 기반 경계 — 이 헌장과 무관): 유료 룸 대여, 독립 강사 세션, 선불 할인.

MAISTUDYMATE 문서 반영 시 이 경계를 명기한다 (해당 반영은 MAISTUDYMATE 흐름 관할).

3. 부 헌장 (참조 — 단일 정본 원칙)

부(富) 레이어의 산식·트리거는 D002-wealth-charter.md가 정본이며 이 문서에 중복 기재하지 않는다.

백로그 #18이 요구하는 요소의 소재 확인: 산식 min(0.5%×매출, $500) = D002 §2 ·

자동 트리거·무재량 = §3 · 데뷔 플로어($250 미달 이월) = §3 · 룩백(founding cohort) = §3 ·

"회차별 재량 결의(ex-gratia)로 확정되며 지급 약속 아님" = §4.

4. 잉여 환류 규정 (surplus reflux — 풀 단위)

  1. 환류는 풀 단위로만 이루어진다. 개인 점수↔돈 직교환은 금지하며, 개인 점수와 환류액을 잇는 어떤 산식도 만들지 않는다 ("점수당 환율" 금지 — 소급 임금화 차단).
  2. total 스칼라 순함수 금지: 4렌즈 합산치(total)만을 입력으로 하는 배분·랭킹 산식을 금지한다 — 단일 종합점수 금지선의 헌법화 (A005 의장 지적).
  3. 환류 기준은 매출이 아닌 정의된 순잉여(부록 A의 net)다.
  4. 법적 구조는 grant(증여) — 참여자의 청구권은 존재하지 않으며, 회사는 지급 유보 권한을 가진다 (D002 §4의 ex-gratia 성격과 동일).
  5. surplus_reflux_rate 및 잉여 정의의 변경은 T3 게이트 + 참여자 사전 고지 기간을 요한다.
  6. attestation 행위는 환류 산식에서 영구 제외 (D002 §5, 원칙 1).
